Your game. Plus a side quest.

SideQuest is a small window that stays on top of your game. Inside it runs the real CrazyGames site, cropped down to just the game, so saves, logins and multiplayer work exactly as on the website.

Always on top

Dock it left or right, resize it, make it see-through. It stays above WoW until you hide it.

One key to swap

Ctrl+Alt+Space moves your keyboard between the mini game and WoW. No alt-tab, no lost focus.

Any CrazyGames game

Eight quick favourites are one hotkey away, and Browse opens the whole CrazyGames library.

Set it up in a minute.

  1. In WoW, use Windowed (Fullscreen). Options → Graphics → Display Mode. Plain Fullscreen hides every overlay, including this one.
  2. Download and unzip. On Windows, run SideQuest.exe. If you see “Windows protected your PC”, click More info → Run anyway.
  3. On a Mac, drag SideQuest.app into Applications. The first time, open System Settings → Privacy & Security → Open Anyway.
  4. Press Ctrl+Alt+Space to play. The purple line means the game has your keyboard. Press it again to get back to WoW.

SideQuest FAQ.

Can this get my WoW account banned?

SideQuest never touches WoW. It’s a separate window on your desktop, the same kind of thing as the Discord or OBS overlays. It doesn’t read WoW’s memory, inject anything or change game files.

Why isn’t it a WoW addon?

WoW addons can’t show web pages. The Pokémon addons rebuilt a whole Game Boy inside WoW’s scripting language, which works for one console but not for thousands of web games. A separate window can run any of them.

Why does Windows or macOS warn me?

The app isn’t code-signed yet, so your system can’t check who made it. The code is public on GitHub, and the warning goes away once we sign it.

Does it work with other games?

Yes. Anything that runs in a window or in borderless fullscreen works, not just WoW.

I play on a Mac. Is that a different app?

It’s a native Mac version with the same features and the same hotkeys, using Control+Option instead of Ctrl+Alt.
